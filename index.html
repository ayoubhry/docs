Docker

Procédure d'installation complète de l'environnement de conteneurisation Docker sur un système Debian 12 (Bookworm).

1. Prérequis et dépendances

Bash
sudo apt update
sudo apt install -y ca-certificates curl gnupg lsb-release

2. Ajout de la clé GPG officielle et du dépôt

Bash
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/debian/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/debian $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

3. Installation du moteur Docker

Bash
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

4. Post-installation (Utilisation sans sudo)

Par défaut, l'exécution des commandes Docker nécessite les privilèges root. Ajoutons l'utilisateur actuel au groupe docker :

Bash
sudo usermod -aG docker $USER
newgrp docker

Docker Compose

Gestion et déploiement d'architectures multi-conteneurs à l'aide de fichiers descriptifs YAML.

1. Structure type d'un projet

Il est recommandé de dédier un répertoire par stack applicative :

📁 mon-application/
└── 📄 docker-compose.yml

2. Exemple concret : Serveur Web Nginx avec volumes

YAML
version: '3.8'

services:
  webserver:
    image: nginx:latest
    container_name: nginx_production
    ports:
      - "8080:80"
    volumes:
      - ./html:/usr/share/nginx/html
    restart: unless-stopped

3. Commandes fondamentales d'administration

ActionCommande
Démarrer la stack en tâche de fonddocker compose up -d
Arrêter et supprimer les conteneursdocker compose down
Consulter les logs en temps réeldocker compose logs -f
Vérifier le statut des conteneursdocker compose ps

VLAN — Cisco Packet Tracer

Configuration de réseaux locaux virtuels (VLAN) pour segmenter les flux et optimiser la sécurité au sein d'un commutateur Cisco.

1. Création et nommage des VLANs

Cisco CLI
Switch> enable
Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name Informatique
Switch(config-vlan)# exit
Switch(config)# vlan 20
Switch(config-vlan)# name Administratif
Switch(config-vlan)# exit

2. Assignation des ports d'accès (Access)

Exemple d'affectation de l'interface FastEthernet 0/1 au VLAN 10 :

Cisco CLI
Switch(config)# interface fastEthernet 0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# exit

3. Configuration d'une liaison Trunk

Pour faire transiter plusieurs VLANs vers un routeur ou un autre commutateur sur l'interface GigabitEthernet 0/1 :

Cisco CLI
Switch(config)# interface gigabitEthernet 0/1
Switch(config-if)# switchport mode trunk
Switch(config-if)# exit

VPN — WireGuard

Mise en œuvre d'un tunnel VPN sécurisé, moderne et performant pour l'accès distant à l'infrastructure.

1. Installation du package

Bash
sudo apt update && sudo apt install -y wireguard

2. Génération des paires de clés (Serveur)

Bash
wg genkey | sudo tee /etc/wireguard/server_private.key | wg pubkey | sudo tee /etc/wireguard/server_public.key

3. Configuration du fichier Serveur (`/etc/wireguard/wg0.conf`)

Configuration INI
[Interface]
Address = 10.0.0.1/24
SaveConfig = true
ListenPort = 51820
PrivateKey = [Contenu_De_server_private.key]

# Exemple de déclaration d'un client (Peer)
[Peer]
PublicKey = [Cle_Publique_Du_Client]
AllowedIPs = 10.0.0.2/32

4. Activation du service tunnel VPN

Bash
sudo systemctl enable wg-quick@wg0
sudo systemctl start wg-quick@wg0

GLPI (Gestionnaire Libre de Parc Informatique)

Outil ITSM open-source de gestion de parc et de tickets d'incidents.

Installation manuelle (Debian 12)

1. Stack LAMP

Bash
sudo apt install -y apache2 mariadb-server php php-mysql php-curl php-gd php-intl \
php-mbstring php-xml php-zip php-ldap php-apcu php-xmlrpc php-soap libapache2-mod-php

2. Créer la base de données

SQL
CREATE DATABASE glpi CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'glpiuser'@'localhost' IDENTIFIED BY 'MotDePasseForte123!';
GRANT ALL PRIVILEGES ON glpi.* TO 'glpiuser'@'localhost';
FLUSH PRIVILEGES;

Déploiement alternative via Docker Compose

YAML
name: glpi
services:
  glpi:
    image: glpi/glpi:latest
    restart: unless-stopped
    container_name: glpi
    ports:
      - "8282:80"
    environment:
      MYSQL_HOST: db
      MYSQL_DATABASE: glpi

Samba (NAS)

Mise en place d'un serveur de partage de fichiers multiplateforme (Windows/Linux) s'appuyant sur le protocole SMB.

1. Installation du service Samba

Bash
sudo apt update && sudo apt install -y samba samba-common-bin

2. Création de l'arborescence et gestion des droits locaux

Bash
sudo mkdir -p /srv/samba/partage_sisr
sudo chown -R nobody:nogroup /srv/samba/partage_sisr
sudo chmod -R 775 /srv/samba/partage_sisr

3. Édition du fichier de configuration (`/etc/samba/smb.conf`)

Ajoutez le bloc suivant tout à la fin du fichier :

Configuration INI
[Partage-SISR]
   comment = Espace d'échange Réseau
   path = /srv/samba/partage_sisr
   browseable = yes
   read only = no
   guest ok = yes
   create mask = 0775
   directory mask = 0775

4. Application des paramètres

Bash
sudo testparm
sudo systemctl restart smbd
sudo systemctl restart nmbd

Pi-Hole

Bloqueur de publicités et traqueurs au niveau DNS faisant office de puit de filtrage (DNS Sinkhole) pour le réseau local.

Installation automatisée

Bash
sudo apt install curl -y
curl -sSL https://install.pi-hole.net | bash

Une interface graphique d'installation s'ouvre pour valider l'adresse IP fixe et l'interface d'écoute. Après installation, modifiez le mot de passe web de sécurité :

Bash
pihole -a -p

Active Directory

Déploiement et administration d'un annuaire centralisé Active Directory DS sous Windows Server 2019.

Environnement cible

Windows Server 2019 Standard configuré en adresse IP Statique locale avant promotion.

1. Configuration IP Initiale

Paramètre RéseauValeur Appliquée
Adresse IPv4 fixe192.168.1.10
Masque de sous-réseau255.255.255.0
Serveur DNS préféré127.0.0.1 (Boucle locale)

2. Ajout des Rôles via PowerShell

Il est possible de passer par l'assistant graphique ou d'accélérer l'installation via la console d'administration PowerShell root :

PowerShell
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools

3. Promotion en Contrôleur de Domaine (Nouveau Domaine)

PowerShell
Install-ADDSForest -DomainName "rostand.local" -CreateDnsDelegation:$false -DatabasePath "C:\Windows\NTDS" -LogPath "C:\Windows\NTDS" -SysvolPath "C:\Windows\SYSVOL" -Force
